# 行为准则

[English](CODE_OF_CONDUCT_EN.md)

本仓库希望为所有参与者提供友好、尊重和安全的协作环境。本文适用于 issue、pull request、讨论、评论、代码审查以及与仓库相关的任何公共沟通。

## 我们期望的行为

- 使用礼貌、专业的语言交流。
- 关注代码、文档和问题本身，而不是个人。
- 在讨论技术分歧时，尽量给出可验证的事实、复现步骤和权衡理由。
- 在审查和协作时保持耐心，尊重不同经验背景。
- 发现问题时，优先帮助定位、复现和修复，而不是追究责任。

## 不可接受的行为

- 人身攻击、侮辱、骚扰、歧视或威胁。
- 恶意刷屏、故意破坏讨论、持续带偏话题。
- 公开泄露他人隐私、密钥、凭据或其他敏感信息。
- 以任何形式鼓励暴力、仇恨或非法行为。
- 利用职位、权限或人际关系施压他人接受不当行为。

## 维护者的责任

维护者应以一致、克制和公平的方式执行本准则，并优先保护受影响的人。必要时，维护者可以删除不当内容、限制互动或拒绝协作。

## 举报方式

如果你认为某次互动违反了本准则，请通过仓库维护者的私下联系方式或 GitHub 的私密举报能力联系维护者，并尽量提供：

- 相关链接或截图；
- 事件发生时间；
- 涉及的账号或讨论上下文；
- 你希望维护者采取的处理方式。

## 执行范围

本准则适用于仓库贡献过程中的公共与半公共互动。仓库维护者保留根据具体情况解释和执行本准则的权利。
